# Indian Heart Association — Premium React Redesign

## Run
```bash
npm install
npm run dev
```

## Routes
- `/` — Premium home page
- `/course/2-day-cpr-first-aid` — Course detail page

## Structure
- `src/components/Navbar.jsx` + `Navbar.css`
- `src/pages/Home.jsx` + `Home.css`
- `src/pages/CourseDetail.jsx` + `CourseDetail.css`
- No global CSS file.
- No `data.js`; page content is kept inside each page file.
- Images are kept in `public/images`.
- Poppins is used throughout.

The included image assets are crops prepared from the supplied reference screenshots so the project works immediately without external image dependencies.
